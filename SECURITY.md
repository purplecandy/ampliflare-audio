# Security Policy

## Supported Versions

Fixes go into the newest release. The app updates itself, so that is the
version most people run.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability

Please report it in private, not in a public issue. Use the
[Report a vulnerability](https://github.com/purplecandy/ampliflare-audio/security/advisories/new)
button on the Security tab of this repo.

A good report says which version and system you used. Steps to make it
happen again help a lot.
